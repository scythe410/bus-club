# Sri Lanka 3D Bus model

Author: lk motionfx (https://sketchfab.com/automaker)

The downloaded GLB is included with its original textures. Runtime adaptations in
Bus Club rotate, scale and center the model, batch stationary meshes, animate the
wheels, adjust material response, add editable livery panels and a destination
sign, and recolor the bumper accent. The underlying mesh is not rigged for doors,
mirrors, seating or other independently configurable parts.

Nil Kirilli / Blue Chick 02 adaptation (2026): runtime UV repaint, window alpha
cutouts, replacement blue passenger seating, curtains, roof liner and lighting,
chrome/gold front equipment, mirrors, rear lamps/ladder/trim, Sinhala signage,
and an original AI-generated blue airbrush mural. The original GLB file remains
unmodified. Reference sources and approximation limits are documented in
`review/nil-kirilli-reference.md`.

Dam Rajina / S & S Group adaptation (2026): independently cached runtime variant
of the same licensed GLB, with magenta UV repaint, original pale sweeping artwork,
Sinhala/English signs, rounded front crown, lower chrome bullbar, LED rear lamps,
burgundy/cream seating and decorated cabin ceiling. No third-party game skins or
models are included. Google Images reference sources and remaining approximations
are documented in `review/bus-references.md`. Both variants retain the original
model attribution and share the original unchanged GLB file.

Dam Rajina mural update (2026): an original AI-generated magenta macaw, silver
tribal scrollwork and floral mural replaces the initial simple painted curves.
Both buses add independent rear passenger door geometry and UV cutouts. These
are runtime adaptations of the same credited GLB. See
`review/dam-rajina-mural.md` for the generation prompt, references and assumptions.

Nil Kirilli photo-reference update (26 October 2026): generated pale-woman/tribal
side mural, the same portrait projected across separate grille slats, generated
Sinhala vinyl window decals, marbled nose and rear panels, open rear stairwell,
folded door leaves, blue bumper, silver window rails and revised rear ladder.
These remain runtime adaptations of the credited original unchanged GLB.
Prompts, saved asset paths and approximation limits are in
`review/nil-kirilli-replica.md`.
